# Comms archive

Verbatim copies of one-off communications sent OUTSIDE the app's own
broadcast system (which needs no archive — its templates are code, in
`backend/app/services/email.py`, and every real send is audit-logged).

| File | Sent | Audience | Channel |
|---|---|---|---|
| `2026-07-20-staff-wc26-wrapup-email.html` | 2026-07-20 | All Atlas Insurance staff (participants and non-participants) | Outlook, pasted as HTML |

The staff wrap-up email announces the WC26 pool result (champion
Matthew Ellul, 183 entries, James Vella runner-up/Trionda), thanks
Atlas Insurance and the organising team by name, invites feedback from
players and non-players alike, and points everyone at the now-public
wrap-up page. The Atlas logo is embedded as base64 so the file is
self-contained — open it in a browser to see exactly what recipients
saw.
